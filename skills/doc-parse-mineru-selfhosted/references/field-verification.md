# 字段核验

## 取值与比对

- 按原标签和单位取值；`Quantity` 与 `Net` 即使同用 kg 也分别处理，不同用途的日期分别保留。
- 关联文档独立取值，对齐标签含义、单位和范围后比较；补值与计算值不作独立互证。
- 内部核对记录保留原标签、原值、单位、locator；补值记来源，计算值记公式及换算依据。
- 翻译有歧义时保留原词或代码。

## 缺项与冲突

| 情况 | 处理 |
|---|---|
| 摘要缺项 | 回原页/块读完整上下文，检查分行数值 |
| 两档均未读出 | 查看原图，无法确认则标为不可读或待核实，不记作原文缺项 |
| 重复异常、编号/单位冲突、双档分歧 | 回原页/块或原图核对，不单凭档位选值 |
| 尚未读取相关内容 | 继续读取后再判断 |

文本层为空不能证明原页为空；`is_image_based=false` 不保证文本完整。无法查看原图时，保留疑点供后续核对。

## 核验结论

回读确认写入结果，内容核验需对照原始来源；合计一致不代表明细正确。结论注明实际核对范围、差异与未决项。
